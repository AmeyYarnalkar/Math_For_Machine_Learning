# Math_For_Machine_Learning

This repository is a structured walk through the **mathematical foundations
required for machine learning**, built from first principles.

The focus is not on memorizing formulas, but on understanding **why they work**
and how they show up in real ML algorithms.

---

## What This Repository Covers

- 📐 **Linear Algebra**
  - Vectors, matrices, norms
  - Dot product, cosine similarity
  - Eigenvalues, eigenvectors (intuition first)
  - Matrix multiplication and transformations

- 📊 **Probability & Statistics**
  - Random variables and distributions
  - Expectation, variance, covariance
  - Bayes theorem and conditional probability
  - Bias–variance intuition

- 📉 **Calculus for Optimization**
  - Derivatives and partial derivatives
  - Gradients and Jacobians (conceptual focus)
  - Chain rule in ML context
  - Gradient descent from scratch

---

## Who This Is For

- Anyone transitioning into machine learning from software engineering
- People who want **conceptual clarity**, not just library usage
- Learners who care about long-term depth over quick results

---

## Philosophy

> If you can’t explain the math in simple words, you don’t really understand it.

This repository documents my learning process as I build a solid ML foundation.
