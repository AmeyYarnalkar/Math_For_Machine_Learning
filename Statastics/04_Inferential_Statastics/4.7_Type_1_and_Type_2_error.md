
# Type 1 and Type 2 Errors 

##  The Setup 

In hypothesis testing, two things exist:

👉 **Reality** — The null hypothesis (H₀) is either:

* TRUE
* FALSE

👉 **Your Decision** — Based on data you either:

* Reject H₀
* Fail to Reject (Accept) H₀

So there are **4 possible outcomes**.

---

## The Decision Table (Core Idea)

| Reality (Truth) | Your Decision | Result         |
| --------------- | ------------- | -------------- |
| H₀ TRUE         | Reject H₀     |  Type 1 Error |
| H₀ TRUE         | Accept H₀     |  Correct      |
| H₀ FALSE        | Reject H₀     |  Correct      |
| H₀ FALSE        | Accept H₀     |  Type 2 Error |

This table is everything. Understand this and you’re done.

---

##3️ Type 1 Error (False Alarm)

👉 **Definition:**
Rejecting the null hypothesis even though it is actually true.

In simple words:

> You think something changed… but nothing actually changed.

### Example

* H₀: Medicine does NOT work.
* You conclude it works.
* But in reality, it doesn’t.

That’s Type 1 error.

### Probability

This is controlled by:

**α (alpha) = Significance level**

Common values:

* 0.05
* 0.01

---

##  Type 2 Error 

👉 **Definition:**
Failing to reject the null hypothesis even though it is false.

In simple words:

> Something really changed… but you failed to detect it.

### Example

* H₀: Medicine does NOT work.
* Medicine actually works.
* But your test says it doesn’t.

That’s Type 2 error.

### Probability

This is called:

**β (beta)**
