# stimation and Confidence Interval

## Estimate (Point Estimate)

In statistics, we often want to know a **population parameter**
(for example: population mean, variance, proportion).

But measuring the entire population is usually impossible.

So we:

* Take a **sample** of reasonable size.
* Calculate the parameter using the sample.
* Use that value as our **best guess** of the true population value.

This best guess is called a:

👉 **Point Estimate**

### Example

If the sample mean is:

$$
\bar{x} = 50
$$

then 50 is the point estimate of the population mean ( \mu ).

---

## Problem with Point Estimates

A point estimate is only a **single value**.

If we repeat sampling:

* Each sample gives a slightly different estimate.
* So relying on one number alone is risky.

Instead of a single value, we use a **range** that likely contains
the true population parameter.

This range is called a:

👉 **Confidence Interval (CI)**

---

## Confidence Level

The confidence level tells us how reliable our interval method is.

Simple meaning:

If we repeat the sampling process many times and build intervals each time,

* About **95% of those intervals** will contain the true population value
  (for a 95% confidence level).

Important:

It does NOT mean the parameter has 95% probability inside one specific interval.
The parameter is fixed — the interval is what changes.

### Common Confidence Levels

* 90%
* 95%
* 99%

---

## Structure of a Confidence Interval

A confidence interval is built around the point estimate:

$$
\text{Confidence Interval} =
\text{Point Estimate} \pm \text{Margin of Error}
$$

So:

$$
\text{Lower Bound} = \text{Estimate} - \text{Margin of Error}
$$

$$
\text{Upper Bound} = \text{Estimate} + \text{Margin of Error}
$$

---

## Margin of Error (MoE)

Margin of Error tells us:

* how much uncertainty exists
* how far the estimate may be from the true value

### Formula

$$
\text{Margin of Error} =
\text{Confidence Factor} \times \text{Standard Error}
$$

---

## Standard Error (SE)

Standard error measures how much the sample estimate is expected to vary.

### Formula (for mean)

$$
SE = \frac{s}{\sqrt{n}}
$$

Where:

* ( s ) = sample standard deviation
* ( n ) = sample size

### Intuition

* Larger sample size → smaller error → tighter interval
* Higher variability → larger error → wider interval

---

## Confidence Factor

The confidence factor comes from probability distributions.

We use:

### 🔹 Z value

Used when:

* sample size is large
* or population standard deviation is known

Examples:

* 90% → ( Z = 1.645 )
* 95% → ( Z = 1.96 )
* 99% → ( Z = 2.576 )

---

### 🔹 T value

Used when:

* sample size is small
* population standard deviation is unknown

T value depends on:

* confidence level
* degrees of freedom ( (n-1) )

---

## Final Confidence Interval Formula

###  Z-based Confidence Interval

$$
\bar{x} \pm Z \times \frac{s}{\sqrt{n}}
$$

---

### T-based Confidence Interval

$$
\bar{x} \pm t \times \frac{s}{\sqrt{n}}
$$

---

## Why Different Samples Give Different Intervals

Each sample has:

* different mean
* different variability

So every sample produces a slightly different interval.

Confidence level guarantees the **long-run success rate** of the method —
not a guarantee about one specific interval.

---

## Connection to Hypothesis Testing

Confidence intervals and hypothesis testing are tightly linked.

Think of it like this:

* Confidence interval → gives a **range of plausible values**
* Hypothesis testing → checks whether a specific value fits inside that range

Later you’ll see:

* significance level $ \alpha $
* z-test and t-test

are basically two ways of answering the same question from different angles.
