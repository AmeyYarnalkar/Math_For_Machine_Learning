# What is Probability?

**Probability = how likely something is to happen**

* Scale: **0 to 1**

  * `0` → impossible
  * `1` → guaranteed

### Mathematical definition

```
P(Event) = Favorable outcomes / Total possible outcomes
```

**Example**

* Toss a coin
* Outcomes = {H, T} → 2

Probability of Head:

```
P(H) = 1/2
```

---

# What is an Event?

**Event = a specific outcome or group of outcomes you care about**

* Sample Space (S): all possible outcomes
* Event (E): subset of S

**Example**

* Roll a die

```
S = {1,2,3,4,5,6}
```

Event E = “Even number”

```
E = {2,4,6}
```

---

# Why Do We Add Probabilities?

### 👉 Addition answers this question

> What is the chance that **at least one** of these events happens?

Whenever you see **OR**, think **ADDITION**.

---

# Mutually Exclusive Events

### Meaning

**Mutually exclusive = cannot happen at the same time**

If one happens, the other **cannot**.

**Example**

One coin toss:

* Head OR Tail
* You cannot get both

### Mathematical property

```
P(A ∩ B) = 0
```

### Additive rule

```
P(A ∪ B) = P(A) + P(B)
```

**Example**

Die roll

```
A = getting 2 → 1/6
B = getting 5 → 1/6
```

```
P(A or B) = 1/6 + 1/6 = 2/6
```

---

# Non-Mutually Exclusive Events

### Meaning

They **can happen together**.

**Example**

Card draw

```
A = card is red
B = card is king
```

Red king exists → overlap.

### Why simple addition fails

Because the overlap gets **counted twice**.

### Correct additive rule

```
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
```

### Example

Deck of 52 cards

```
Red cards = 26
Kings = 4
Red kings = 2
```

```
P(A ∪ B) = 26/52 + 4/52 − 2/52
```

---

# What Does Addition Really Give Us?

Addition tells us:

> Probability that **at least one event occurs**

Key idea:

* Used when outcomes are **alternatives**
* Language clue → **OR**

---

# Why Do We Multiply Probabilities?

### 👉 Multiplication answers this question

> What is the chance that **both events happen together**?

Whenever you see **AND**, think **MULTIPLICATION**.

---

# Independent Events

### Meaning

One event **does not affect** the other.

**Example**

Tossing two coins.

First toss doesn’t affect the second.

### Multiplication rule

```
P(A ∩ B) = P(A) × P(B)
```

### Example

```
P(Head) = 1/2
```

Two heads:

```
1/2 × 1/2 = 1/4
```

---

# Dependent Events

### Meaning

One event **affects the other**.

Usually happens **without replacement**.

**Example**

Drawing cards without replacement.

### Formula

```
P(A ∩ B) = P(A) × P(B | A)
```

Where

```
P(B | A) = probability of B after A happened
```

### Example

Draw two red cards without replacement.

```
P(first red) = 26/52
```

```
P(second red | first red) = 25/51
```

```
P = (26/52) × (25/51)
```

---

# What Does Multiplication Really Give Us?

Multiplication tells us:

> Probability that **all events happen together**

Key idea:

* Used when events happen **in sequence**
* Language clue → **AND**

---

# Why “Mutually Exclusive” Is NOT Used in Multiplication

Mutually exclusive means

```
P(A ∩ B) = 0
```

Multiplication calculates

```
P(A ∩ B)
```

So if events are mutually exclusive:

* They **cannot happen together**
* Multiplication result is **0**

👉 Mutual exclusivity belongs to **addition (OR)**, not **multiplication (AND)**.
