# Distribution

A **distribution** describes:

* the **possible values (inputs)** a variable can take, and
* **how often** (frequency) or **how likely** (probability) those values occur.

In simple terms:

> **Distribution = values + how common / likely they are**

---

#  What Do We Mean by “Inputs”?

**Input = the value taken by a variable**
Usually denoted by **x**.

Examples:

* Exam score → 60, 70, 85
* Height → 165 cm, 170 cm
* Dice roll → 1, 2, 3, 4, 5, 6

So in any distribution:

* **x-axis → possible values of the variable**

---

#  How Do We Describe Inputs?

There are **two ways**, depending on context:

1. **Frequency** (from real data)
2. **Probability** (theoretical likelihood)

---

#  Frequency-Based Distribution (Empirical)

Here we ask:

> “How many times did this value (or range) appear in the data?”

Example dataset:

```
Scores: 60, 70, 70, 80, 80, 80
```

| Input (x) | Frequency |
| --------- | --------- |
| 60        | 1         |
| 70        | 2         |
| 80        | 3         |

* Inputs → values
* Output → **count**

### Visualization

* **Histogram**

  * x-axis → value bins
  * y-axis → frequency

This shows how data is distributed **in reality**.

---

#  Why Do We Use Bins?

In many cases:

* Data can be **continuous**
* Values can be **very dense**
* Exact duplicates may not exist

Plotting every value would make the graph:

* too large
* noisy
* hard to interpret

So we group values into **bins (ranges)**.

---

#  Probability-Based Distribution

Now we shift perspective and ask:

> “If I randomly choose one outcome, how likely is it?”

Example: fair die

| Input (x) | Probability |
| --------- | ----------- |
| 1         | 1/6         |
| 2         | 1/6         |
| ...       | ...         |

* Inputs → values
* Output → **probability**

Key property:

* **Sum of all probabilities = 1**

---

#  Probability Distribution

A **probability distribution** answers:

> “If I randomly pick a value, how likely is it to fall within a given range?”

Important points:

* Probability belongs to **ranges**, not isolated points
* Bin width can be chosen freely
* Total probability always remains **1**, independent of bin width

---

#  What Is a Distribution Function?

A **distribution function** maps:

* **input values or ranges**
  to
* their **probabilities**

As bin width changes:

* Wide bins → bar chart
* Thinner bins → more bars
* Extremely thin bins → bars blend into a **curve**

This curve is a more refined representation of probability.

---

#  Types of Probability Distribution Functions

Based on the nature of the random variable, we have two main types:

---

## Probability Mass Function (PMF)

Used for **discrete random variables**.

Characteristics:

* Countable values
* Gaps are countable
* Restricted outcomes

Examples:

* Dice rolls
* Number of students
* Number of cars

### Representation

* Input → individual values
* Output → probability
* Visualization → **bar chart**

### Interpretation

* Height of bar = probability of that value
* Probability is directly assigned to values

This is called a **Probability Mass Function** because probability is attached to **mass points**.

---

## Probability Density Function (PDF)

Used for **continuous random variables**.

Characteristics:

* Infinite possible values
* Gaps are extremely small
* Values lie on a continuous scale

Examples:

* Height
* Weight
* Time
* Temperature

### Why bins are still used

* Individual values are impractical
* So we use **very small ranges (bins)**

### Effect of bin width

* Large bins → loss of detail
* Smaller bins → better shape
* As bin width → very small:

  * bars become extremely thin
  * they appear continuous
  * graph becomes a **smooth curve**

---

## How Probability Works in PDF

* Probability of a **single value = 0**
* Probability comes from a **range**
* Probability is calculated as:

> **Area under the curve over that range**

So the PDF shows:

* how probability is **spread** across values
* not probability at a point, but **density around a point**

---

#  Cumulative Distribution Function (CDF)

So far:

* PMF and PDF describe **individual probabilities**

CDF answers:

> “What is the probability that the value is **less than or equal to x**?”

### How CDF works

* It accumulates probability from the left
* For PMF → sum of bars
* For PDF → area under the curve

Key properties:

* Starts at 0
* Always increases
* Ends at 1

---

## Important Connection: CDF and PDF

A crucial insight:

> **The slope (gradient) of the CDF at a point represents the probability density at that point in the PDF.**

Meaning:

* Steep CDF → high probability density
* Flat CDF → low probability density

So:

* **PDF = derivative of CDF**
* **CDF = integral of PDF**

This directly connects the two concepts.

---

# Final Intuition 

* **PMF** → probability at a value
* **PDF** → probability density around a value
* **CDF** → probability up to a value
