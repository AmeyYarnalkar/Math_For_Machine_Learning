# Bernoulli Distribution (Setup)

Random variable ( X ) takes values:

$$
X =
\begin{cases}
1 & \text{with probability } p \\
0 & \text{with probability } 1-p
\end{cases}
$$

PMF:
$$
P(X=k)=p^k(1-p)^{1-k}, \quad k\in{0,1}
$$

This is the **only formula** we’ll assume.

---

## 1. Mean (Expected Value)

### Definition of mean

$$
\mathbb{E}[X] = \sum x \cdot P(X=x)
$$

### Apply to Bernoulli

$$
\mathbb{E}[X] = 0\cdot P(X=0) + 1\cdot P(X=1)
$$

$$
= 0\cdot(1-p) + 1\cdot p
$$

$$
\boxed{\mathbb{E}[X] = p}
$$

### Interpretation

> The mean of a Bernoulli variable is the **probability of success**

This is why averages of 0/1 data converge to probabilities.

---

## 2. Variance

### Definition

$$
\text{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2
$$

---

### Step 1: Compute ( \mathbb{E}[X^2] )

Since $ X \in {0,1} $:

* $ 0^2 = 0 $
* $ 1^2 = 1 $

So:
$$
\mathbb{E}[X^2] = 0^2\cdot(1-p) + 1^2\cdot p = p
$$

---

### Step 2: Plug in

$$
\text{Var}(X) = p - p^2
$$

$$
\boxed{\text{Var}(X) = p(1-p)}
$$

---

### Interpretation

* Maximum variance at ( p=0.5 )
* No variance when outcome is certain (( p=0 ) or ( 1 ))

---

## 3. Standard Deviation

### Definition

$$
\sigma = \sqrt{\text{Var}(X)}
$$

So:
$$
\boxed{\sigma = \sqrt{p(1-p)}}
$$

---

## 4.  Median

Let $X$ be a Bernoulli random variable:

* $X = 1$ with probability $p$
* $X = 0$ with probability $1 - p$

The median is the value where the **cumulative probability reaches or crosses 0.5**.

---

### Case ( p > 0.5 )

* $1 - p < 0.5$
* So:
  $$
  P(X \le 0) = 1 - p < 0.5
  $$
* Cumulative probability has **not yet reached 0.5** at 0
* At 1:
  $$
  P(X \le 1) = 1
  $$

The first value where cumulative probability crosses 0.5 is **1**

**Median = 1**

---

### Case  ( p < 0.5 )

* $1 - p > 0.5$
* So:
  $$
  P(X \le 0) = 1 - p > 0.5
  $$

Cumulative probability already crosses 0.5 at **0**

**Median = 0**

---

### Case ( p = 0.5 )

* (1 - p = 0.5)
* So:
  $$
  P(X \le 0) = 0.5
  $$
* And:
  $$
  P(X \le 1) = 1
  $$

Both 0 and 1 satisfy the median condition

**Median = 0 or 1 (both are valid)**

---

## Final Summary

$$
\text{Median} =
\begin{cases}
0 & \text{if } p < 0.5 \\
{0,1} & \text{if } p = 0.5 \\
1 & \text{if } p > 0.5
\end{cases}
$$

---

### takeaway 

* If success is more likely than failure → median is 1
* If failure is more likely than success → median is 0
* If both are equally likely → both are medians

## 5. Mode

### Definition

The **mode** is the value with **highest probability**.

---

### Bernoulli probabilities

* $ P(X=1) = p $
* $ P(X=0) = 1-p $

---

### Cases

* If $ p > 0.5 $ : mode = **1**
* If $ p < 0.5 $ : mode = **0**
* If $ p = 0.5 $ : both are modes

$$
\boxed{
\text{Mode} =
\begin{cases}
0 & p < 0.5 \\
{0,1} & p = 0.5 \\
1 & p > 0.5
\end{cases}
}
$$

---

## 🔗 Final Summary Table

| Measure            | Result                   |
| ------------------ | ------------------------ |
| Mean               | ( p )                    |
| Variance           | ( p(1-p) )               |
| Standard Deviation | ( \sqrt{p(1-p)} )        |
| Median             | 0 / 1 (depends on ( p )) |
| Mode               | 0 / 1 (depends on ( p )) |

---

## 🔑 Deep insight (don’t skip)

Because Bernoulli values are **0 and 1**:

* ( X^2 = X )
* That’s why variance derivation is so clean
* This property is used **everywhere** in ML (logistic loss, cross-entropy)
