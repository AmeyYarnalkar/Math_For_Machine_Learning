

# Bernoulli Distribution

## What problem does it model? 

The **Bernoulli distribution** models situations where there are **only two possible outcomes**.

These outcomes are usually framed as:

* **Success**
* **Failure**

There are **no other possibilities**.

Examples:

* Coin flip (Head / Tail)
* Yes or No question
* Pass / Fail
* Click / No click

---

## Random Variable Definition

Let **X** be a random variable such that:

* ( X = 1 ) → success
* ( X = 0 ) → failure

So the random variable can take **only one of two values**.

---

## Nature of the Input (PMF vs PDF)

* The input values are **discrete**
* Possible values are **countable**
* Only two values exist: {0, 1}

Therefore:

> Bernoulli distribution uses a **Probability Mass Function (PMF)**

---

## Meaning of the Output

The output represents **probability** (not density).

* ( P(X = 1) = p ) → probability of success
* ( P(X = 0) = 1 - p = q ) → probability of failure

Because there are only two outcomes:
[
p + (1 - p) = 1
]

This works **only because the outcome space has exactly two values**.

---

## Parameters and Their Intuition

The Bernoulli distribution has **one parameter**:

* **p** → probability of success

Interpretation:

* Higher ( p ) → success more likely
* Lower ( p ) → failure more likely

There is **no other parameter** controlling shape or spread.

---

## Shape of the Distribution

* The graph has **two bars**
* One bar at ( x = 0 )
* One bar at ( x = 1 )

Bar heights:

* Height at 1 → ( p )
* Height at 0 → ( 1 - p )

There is **no curve**, because outcomes are discrete.

---

## Interpretation of Probability

Since this is a PMF:

* Probability is assigned to **exact values**
* Height of the bar **is the probability**

Examples:

* ( P(X = 1) = 0.5 ) → 50% chance of success
* ( P(X = 0) = 0.5 ) → 50% chance of failure

---

## Mathematical Representation (PMF)

The Bernoulli PMF is:

$$
P(X = k) = p^k (1 - p)^{1 - k}
$$

Where:

* $ k \in {0, 1} $
* $ p $ = probability of success

### Why this formula works

* If ( k = 1 ):
  $$
  P(X=1) = p^1 (1-p)^0 = p
  $$

* If ( k = 0 ):
  $$
  P(X=0) = p^0 (1-p)^1 = 1-p
  $$

So one formula handles **both outcomes**.

---

## Assumptions

* Only **two outcomes**
* Outcomes are **mutually exclusive**
* Probability ( p ) is **fixed**

If any of these fail, Bernoulli is **not appropriate**.

---

## Practical Usage

Bernoulli distribution is used as the **building block** for many models:

* Binary classification
* Logistic regression
* Binomial distribution (multiple Bernoulli trials)
* Yes/No decision modeling
