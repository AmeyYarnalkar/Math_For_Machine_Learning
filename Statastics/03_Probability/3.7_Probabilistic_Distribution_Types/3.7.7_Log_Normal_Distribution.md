# What is a Log-Normal Distribution?

A variable is **log-normal** when:

👉 Its **logarithm** follows a normal (Gaussian) distribution.

In plain words:

```
If log(X) is normal → X is log-normal.
```

So instead of the values themselves being bell-shaped, their **log values** are.

---

# What does that *mean* intuitively?

Gaussian assumes **additive effects**:

```
final value = sum of many small influences
```

Log-normal appears when things grow **multiplicatively**:

```
final value = product of many small factors
```

That’s the core difference.

---

# Real-world things that become log-normal

You’ll see this pattern whenever values:

* Cannot be negative
* Grow by percentages or ratios
* Have many small multiplicative changes

Examples:

✅ Income distribution
✅ Stock prices (rough approximation)
✅ Population growth
✅ File sizes on the internet
✅ Time taken for tasks

Why?

Because growth often happens like:

```
new_value = old_value × growth_factor
```

Multiply enough random factors → log-normal shape emerges.

---

# How it looks (visually)

Unlike Gaussian:

* Not symmetric
* Long tail to the right (Right Skewed)
* Starts near zero but never goes negative

Shape intuition:

```
Normal       →   /\  (balanced)
Log-normal   →   /-----> (right-skewed)
```

Most values small, few extremely large ones.
