# Median for Probabilistic Distribution

## What does “median” mean at its root?

Before probability, before distributions, before formulas:

> **Median simply means the middle.**

That’s the core idea.

---

# Start From the Simplest Case (No Probability)

Take raw data:

```
2, 4, 7, 10, 15
```

Middle value = **7**

Why?

* 2 values lie on the left
* 2 values lie on the right

So the median is the value that **splits the data into two equal halves**.

---

# Now Introduce Probability (Why the CDF Appears)

In probability problems we often:

* do **not have observed data yet**
* only know **how likely different values are**

So we cannot count **number of observations**.

Instead we measure **probability mass**.

The question becomes:

> At what value does half of the total probability lie to the left?

That is why **cumulative probability** becomes important.

---

# Formal Definition

A value **m** is a median if:

```
P(X ≤ m) ≥ 0.5
P(X ≥ m) ≥ 0.5
```

For continuous distributions this simplifies to:

```
F(m) = 0.5
```

where **F(x)** is the cumulative distribution function (CDF).

---

# Why Exactly 50%?

Because **median means the halfway point**.

* If cumulative probability is **less than 0.5**, you are still in the left half.
* If it is **greater than 0.5**, you have crossed into the right half.

So the median occurs **where cumulative probability reaches the halfway mark**.

---

# Why Cumulative Probability Instead of Point Probability?

Because probability in distributions is **not concentrated at a single value**.

Especially in continuous distributions:

```
P(X = x) = 0
```

So asking:

> “Does this specific value have 50% probability?”

does not make sense.

Instead we ask:

> “Up to what value has 50% of the probability accumulated?”

That is exactly what the **CDF measures**.

---

# One-Sentence Logic Chain

Median means **middle**
→ middle means **half on each side**
→ probability replaces **counts**
→ cumulative probability reaching **50% defines the median**

---

# Why “Equal OR Crossing” 50%?

Because distributions behave differently.

### Continuous distributions

The CDF is **smooth**, so it usually hits **exactly 0.5**.

### Discrete distributions

The CDF moves in **jumps**, so it may **skip over 0.5**.

Example:

```
0.3 → 0.7
```

It never equals 0.5 exactly.

So we define the median as:

> the smallest value where cumulative probability is **at least 0.5**

```
F(m) ≥ 0.5
```

This definition works for **both discrete and continuous distributions**.
