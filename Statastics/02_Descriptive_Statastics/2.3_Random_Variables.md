

# Random Variables

## What is a Random Variable?

A **random variable** is a **numerical representation of outcomes of a random process**.

Plain English:

> A random variable is a **translator** that converts real-world uncertainty
> into numbers so we can do math on it.

Formally:

> A random variable is a **function** that assigns a number
> to each possible outcome of an experiment.

---

## Why Random Variables Exist (Very Important)

Real-world outcomes are:

* Words (Head / Tail)
* Events (Rain / No rain)
* Objects (Customer buys / doesn’t buy)

Math works on **numbers**, not words.

👉 Random variables bridge **probability ↔ mathematics**.

---

## Representation

Random variables are usually written as:

* **Capital letters**: (X, Y, Z)

Specific values they take are written as:

* **Lowercase**: (x, y, z)

---

## Core Concept (Coin Toss Example)

### Random Experiment

Flip a coin
Possible outcomes:

* Heads
* Tails

You **cannot compute mean, variance, or probability** on words.

---

### Define a Random Variable

Let (X) be a random variable:

* If Heads → (X = 1)
* If Tails → (X = 0)

Now:

* Outcomes are numerical
* You can compute:

  * Mean (expected value)
  * Variance
  * Probability distribution

👉 This is the **exact reason random variables exist**.

---

## What a Random Variable Enables

Once outcomes are numeric, you can:

* Measure uncertainty
* Model randomness
* Apply statistics
* Train ML models

Without random variables:
👉 **Probability theory collapses**

---

## Types of Random Variables

Random variables are classified based on
**the type of values they can take**.

---

## Discrete Random Variable

### Definition

A random variable that takes **countable values**
(usually integers, with gaps).

### Characteristics

* Values are **separate**
* You can list them
* Counting-based

### Examples

* Number of children in a family: 0, 1, 2, 3…
* Number of emails received in an hour
* Dice roll outcome

👉 In ML:

* Used in **classification**
* Mode and probability mass functions matter

---

## Continuous Random Variable

### Definition

A random variable that takes **any real value**
within a given range.

### Characteristics

* Values are **measurable**
* Infinite possibilities between two points
* Exact value probability is effectively zero

### Examples

* Height of a person (175.42 cm)
* Time taken to finish a task
* Temperature

👉 In ML:

* Used in **regression**
* Mean and variance dominate behavior

---

## Mental Model 

* **Random experiment** → real-world uncertainty
* **Random variable** → numerical mapping
* **Statistics & ML** → math on those numbers

No random variables
→ no distributions
→ no expectations
→ no ML models
