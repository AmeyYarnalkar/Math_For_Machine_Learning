

#  Percentiles and Quartiles

## Percentage (Base Concept)

A **percentage** tells how much a part contributes to the whole.

$$
\text{Percentage} = \frac{\text{part}}{\text{total}} \times 100
$$

👉 Interprets everything on a **0–100 scale**

---

## Percentile

### Definition

A **percentile** is a value **below which a certain percentage of observations fall**.

Plain English:

> If a value is at the **p-th percentile**, then **p% of the data lies below it**.

---

### Percentile Rank (Given a Value)

If you already have a value (x):

$$
\text{Percentile of } x =
\frac{\text{Number of observations below } x}{\text{Total observations}} \times 100
$$

👉 This tells **where a value stands** relative to others.

---

### Finding the Value at a Given Percentile

Steps:

1. Sort the data
2. Compute the **position**

$$
\text{Position} = \frac{p \times (n + 1)}{100}
$$

* (p) → desired percentile
* (n) → sample size

The value at this position is the **p-th percentile**.

---

### Why (n + 1)?

This is important.

* Data values represent **intervals**, not exact boundaries
* Using (n + 1) places percentiles **between observations**
* It gives a **less biased estimate**, especially for small samples
* It aligns percentiles with **order-statistics theory**

👉 Not the only formula, but this one is:

* Simple
* Common
* Statistically reasonable

(Software may use slightly different rules.)

---

## Quartiles

### Definition

**Quartiles** divide sorted data into **four equal parts**.

| Quartile | Percentile | Meaning        |
| -------- | ---------- | -------------- |
| Q1       | 25th       | 25% data below |
| Q2       | 50th       | Median         |
| Q3       | 75th       | 75% data below |

---

### Interpretation

* **Q1** → lower spread
* **Q2** → center
* **Q3** → upper spread

Quartiles describe **distribution shape**, not just center.

---

## Interquartile Range (IQR)

### Definition

$$
\text{IQR} = Q3 - Q1
$$

### What It Measures

* Spread of the **middle 50%** of the data
* **Robust measure of dispersion**

---

### Why IQR Matters

* **Not affected by outliers**
* Preferred for skewed data
* Used in:

  * Box plots
  * Outlier detection

👉 Outliers are often defined as:
$$
< Q1 - 1.5 \times IQR \quad \text{or} \quad > Q3 + 1.5 \times IQR
$$

---

## ML Reality Check

* Percentiles are used in:

  * Feature scaling
  * Robust normalization
  * Performance benchmarks
* Quartiles + IQR help:

  * Detect outliers
  * Understand skewness
  * Avoid mean-based traps

Mean lies.
Median helps.
Quartiles **tell the full story**.

---

## Mental Model 

* **Percentile** → relative position
* **Quartiles** → structured percentiles
* **IQR** → robust spread
