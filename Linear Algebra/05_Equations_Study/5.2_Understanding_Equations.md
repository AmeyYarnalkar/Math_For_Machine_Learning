

## Straight Line Equation

### Equation

$
y = mx + b
$

### What each part REALLY means

* **x** → input (feature)
* **y** → output (prediction)
* **m** → how strongly x affects y

  * bigger m = steeper change
* **b** → starting point

  * value of y when x = 0

### Layman explanation

This equation says:

> “Start at **b**, then for every 1-unit increase in x, add **m** to y.”

Example (real-life thinking):

* x = hours studied
* y = marks
* m = 5
* b = 20

Meaning:

* Even with 0 hours → 20 marks
* Every extra hour → +5 marks

## Plane Equation

### Equation

$
z = ax + by + c
$

### What each part means

* **x, y** → inputs (features)
* **z** → output (prediction)
* **a** → impact of x
* **b** → impact of y
* **c** → base value (offset)

### Layman explanation

This says:

> “Start at **c**, then adjust output based on x and y.”

Each feature:

* pushes the result **up or down**
* independently

Think of it like:

* x = study hours
* y = sleep
* z = marks

Study adds marks, sleep adds marks, both together decide the final score.

### Visual intuition

* Line → 1 direction
* Plane → flat surface
* Any point on the surface = valid prediction

## Hyperplane Equation (the ML one)

### Equation (general form)

$
y = w_1x_1 + w_2x_2 + \dots + w_nx_n + b
$

### What each part means

* **x₁, x₂, …, xₙ** → features (inputs)
* **w₁, w₂, …, wₙ** → importance of each feature
* **b** → bias (starting point)
* **y** → prediction

### Layman explanation

This equation says:

> “Take every input, multiply it by how important it is, add them all, then add a base value.”

That’s it.

### Example intuition

If:

* x₁ = experience
* x₂ = skills
* x₃ = projects

Then:

* w₁ decides how much experience matters
* w₂ decides how much skills matter
* w₃ decides how much projects matter

The model **learns these weights**.

## Hyperplane for Classification (very important)

Sometimes we don’t want a number — we want a **decision**.

### Equation

$
w_1x_1 + w_2x_2 + \dots + w_nx_n + b = 0
$

### What this means

* This equation defines a **boundary**
* One side → class A
* Other side → class B

If result:

* > 0 → class 1
* < 0 → class 0

### Layman explanation

Imagine a **fence**:

* People on left → allowed
* People on right → rejected

The fence is the hyperplane.
