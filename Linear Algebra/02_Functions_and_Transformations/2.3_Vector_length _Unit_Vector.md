## 1. What is the Magnitude of a Vector? (Layman Definition)

The **magnitude of a vector** is simply its **length**.

Think of a vector as an arrow:

* Direction → where it points
* Magnitude → how long the arrow is

Magnitude answers:

> “How far is this vector from the origin?”

---

## 2. Magnitude of a Vector in 2D

Let the vector be:

```
v = (x, y)
```

### Formula

```
|v| = √(x² + y²)
```

### Why this formula?

It comes directly from **Pythagoras theorem**:

* x = horizontal component
* y = vertical component

---

### Example

```
v = (3, 4)
```

```
|v| = √(3² + 4²)
     = √(9 + 16)
     = √25
     = 5
```

So the vector length is **5 units**.

---

## 3. Generalised Formula (n-Dimensional Vector)

Now the important part — **this works in ANY dimension**.

Let:

```
v = (v₁, v₂, v₃, …, vₙ)
```

### General Formula

```
|v| = √(v₁² + v₂² + v₃² + … + vₙ²)
```

This is also called:

* **Euclidean norm**
* **L2 norm**

---

### Example (3D)

```
v = (1, 2, 2)
```

```
|v| = √(1² + 2² + 2²)
     = √(1 + 4 + 4)
     = √9
     = 3
```

---

### Example (High Dimension – ML Context)

```
v = (2, −1, 4, 3)
```

```
|v| = √(4 + 1 + 16 + 9)
     = √30
```

This is how **distance and similarity** are computed in ML.

---

## 4. Unit Vector — What & Why

### Definition (Very Simple)

A **unit vector** is a vector that has:

```
Magnitude = 1
```

Mathematically:

```
|u| = 1
```

Meaning:

> It represents **direction only**, not size.

---

## 5. Why Unit Vectors Are Important

Unit vectors are used when:

* You only care about **direction**
* You want to **normalize data**
* You compute **cosine similarity**
* You remove scale effects

In ML:

* Feature normalization
* Gradient direction
* Directional similarity

---

## 6. How to Convert Any Vector into a Unit Vector

This is **MANDATORY to remember**.

Let:

```
v ≠ 0
```

### Formula

```
Unit vector u = (1 / |v|) × v
```

Or:

```
u = v / |v|
```

---

### Why this works

* You divide the vector by its own length
* Length becomes **1**
* Direction remains unchanged

---

## 7. Example: Converting to Unit Vector (2D)

```
v = (3, 4)
```

Step 1: Find magnitude

```
|v| = 5
```

Step 2: Divide vector by magnitude

```
u = (1/5) × (3, 4)
  = (3/5, 4/5)
```

Check:

```
|u| = √((3/5)² + (4/5)²)
     = √(9/25 + 16/25)
     = √(25/25)
     = 1
```

✔ Unit vector confirmed

---

## 8. Example: Unit Vector in 3D

```
v = (1, 2, 2)
```

```
|v| = 3
```

```
u = (1/3, 2/3, 2/3)
```

---

## 9. Key Properties of Unit Vectors

1. **Magnitude is always 1**

```
|u| = 1
```

2. **Direction same as original vector**

```
u ∥ v
```

3. **Scaling a unit vector changes only magnitude**

```
k u → magnitude = k
```

4. **Dot product with original vector**

```
v · u = |v|
```
