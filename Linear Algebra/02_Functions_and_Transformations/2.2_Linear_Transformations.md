

## 1. What is a Linear Transformation? 

A **linear transformation** is a function that:

* Takes a vector as input
* Produces another vector as output
* **Preserves structure** of vector space

In simple terms:

> Straight things stay straight, the origin stays fixed, and scaling behaves predictably.

---

### Formal Definition

Let

```
f : V → V
```

If vectors **u, v ∈ V**, then `f` is **linear** **iff** it satisfies **both**:

1. **Additivity**
2. **Homogeneity (Scalar Multiplication)**

Miss even one → **NOT linear**.

---

## 2. Two Core Properties (Non-Negotiable)

### 1️. Additivity

```
f(u + v) = f(u) + f(v)
```

Meaning:

> Transform first, then add
> OR add first, then transform
> Result must be the same

---

### 2️. Homogeneity

```
f(k u) = k f(u)
```

Meaning:

> Scaling the input scales the output by the same factor

---

## 3. Example: Reflection Transformation

Define the function:

```
f(x, y) = (−x, y)
```

This reflects a vector across the **Y-axis**.

---

### Step 1: Apply the function

```
u = (2, 3)
f(u) = (−2, 3)
```

---

## 4. Check Additivity

Let:

```
u = (2, 3)
v = (−2, 3)
```

### Add inputs first:

```
u + v = (0, 6)
```

Apply function:

```
f(u + v) = (0, 6)
```

---

### Apply function separately:

```
f(u) = (−2, 3)
f(v) = (2, 3)
```

Add outputs:

```
f(u) + f(v) = (0, 6)
```

✔ Additivity satisfied

---

## 5. Check Homogeneity

Let:

```
k = 2
u = (2, 3)
```

Scale input:

```
k u = (4, 6)
```

Apply function:

```
f(k u) = (−4, 6)
```

---

Scale output:

```
k f(u) = 2 × (−2, 3) = (−4, 6)
```

✔ Homogeneity satisfied

---

## 6. Final Verdict

Since **both properties hold**:

`f(x, y) = (−x, y)` **is a linear transformation**

### Key geometric truths of linear transformations:

1. **Origin never moves**

```
f(0, 0) = (0, 0)
```

2. **Straight lines remain straight**

   * No curves
   * No bending

3. **Parallel lines stay parallel**

4. Graph always looks “rigidly transformed”

   * Stretch
   * Shrink
   * Rotate
   * Reflect

If you see:

* Curve bending 
* Origin shifting 

Then it’s **NOT linear**.

---

## 8. Where Linear Transformations Are Used (Real ML Use)

### 1. Normalization & Standardization

* Scaling feature values
* Preserves relationships
* Helps gradient descent converge faster

---

### 2. Feature Engineering

* Combining features
* Projecting data into new spaces
* Reducing redundancy

---

### 3. Neural Networks (CORE IDEA)

Every dense layer does:

```
Output = W × Input + b
```

* `W × Input` → **linear transformation**
* `+ b` → **breaks linearity**
* Activation → **adds non-linearity**

Without linear transformations → **no learning**
