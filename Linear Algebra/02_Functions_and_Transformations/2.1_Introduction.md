

## 1. What is a Function? 

A **function** is a **rule** that takes an input from one set and gives **exactly one output** in another set.

One input → one output (no ambiguity).

### Formal Definition

A function maps elements from:

* **Domain** → input set
* **Codomain** → output set

Written as:

```
f : X → Y
```

Meaning:

> Function `f` maps elements of set `X` to elements of set `Y`.

---

### Example

```
f(x) = 2x + 3
```

If:

* x = 1 → f(1) = 5
* x = 2 → f(2) = 7

Every input `x` produces **one unique output**.

---

## 2. What is a Transformation?

### Simple Definition (No Math Jargon)

A **transformation** is a function that **changes something about the input**.

It can change:

* **Magnitude** (size)
* **Direction** (orientation)
* **Dimension** (number of components)

In ML, transformations are applied to:

* Data
* Features
* Vectors
* Matrices

---

## 3. What is Vector Transformation?

### Definition (Plain Language)

A **vector transformation** is a function that:

* Takes a vector as input
* Produces a **new vector**, possibly with:

  * Different size
  * Different direction
  * Different dimension

Written as:

```
f : ℝⁿ → ℝᵐ
```

Where:

* `n` = input dimension
* `m` = output dimension

If `m < n` → **dimensionality reduction**
If `m = n` → shape preserved
If `m > n` → expansion

---

### Example

```
f(x, y, z) = [ x + y , 2z ]
```

* Input vector → 3D
* Output vector → 2D

This is a **3D → 2D transformation**

✔ Dimension reduced
✔ Information compressed

---

## 4. What Does “Direction” Mean? (Simplified Properly)

### Direction (Very Important Concept)

**Direction** refers to:

> **Which axes the vector points along and how strongly**

A vector is not just a number — it has:

* **Magnitude** (length)
* **Direction** (orientation in space)

---

### Example: Direction Change

```
(3, 4) → vector in 2D
```

This vector points:

* 3 units along X-axis
* 4 units along Y-axis

Now transform it:

```
f(x, y) = (x, 0)
```

Result:

```
(3, 4) → (3, 0)

-> Y-axis contribution removed
-> Direction changed
-> Vector now lies only on X-axis
```

---

### 3D → 2D Direction Change

```
(x, y, z) → (x + y, z)
```

Original:

* Movement along X, Y, Z axes

After transformation:

* Combined X & Y into one axis
* Z preserved
* One axis completely removed

➡ Axial behavior changed
➡ Direction compressed
➡ Space reduced

---

## 5. Real-World Transformations (VERY IMPORTANT)

### 1. Feature Scaling (Magnitude Change)

Used in ML preprocessing.

Example:

```
f(x) = x / 100
```

Input:

```
[100, 200, 300]
```

Output:

```
[1, 2, 3]
```

✔ Direction same
✔ Dimension same
✔ Only **magnitude** changed

Used in:

* Gradient descent
* Faster convergence

---

### 2. Rotation (Direction Change)

Rotation changes **orientation**, not size.

Example (2D rotation):

```
(3, 4) → rotated by 90°
```

Becomes:

```
(-4, 3)
```

✔ Magnitude same
✔ Direction changed

Used in:

* Computer vision
* Image augmentation
* Coordinate transforms

---

### 3. Reflection (Axis Flip)

Reflection flips a vector across an axis.

Examples:

* Across Y-axis:

```
(3, 4) → (-3, 4)
```

* Across X-axis:

```
(3, 4) → (3, -4)
```

✔ Magnitude same
✔ Direction flipped

Used in:

* Image flipping
* Data augmentation
* Symmetry detection

## Remember This

* **Functions** define rules
* **Transformations** modify vectors
* **ML = series of transformations**
* Neural networks are just:

```
Input → Linear Transform → Non-linear Transform → Output
```
