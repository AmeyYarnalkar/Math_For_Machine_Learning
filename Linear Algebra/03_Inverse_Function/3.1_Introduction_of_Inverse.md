

## Inverse Function

### Definition

Let
$ f : X \rightarrow Y $

This means:

* Input comes from set **X**
* Output goes to set **Y**

If there exists a function
$ f^{-1} : Y \rightarrow X $
such that it **reverses** the action of $ f $, then $ f^{-1} $ is called the **inverse function** of $ f $.

---

### Formal Conditions

For a function to have an inverse:

* **Every output $ y \in Y $** must come from **exactly one input $ x \in X $**
* i.e., for each $ y $, there exists a **unique** $ x $ such that
  $ f(x) = y $

---

### Mathematical Properties

If $ f^{-1} $ exists, then:

```math
f(f^{-1}(y)) = y \quad \forall y \in Y
```

```math
f^{-1}(f(x)) = x \quad \forall x \in X
```

These two equations mean:

* Applying a function and then its inverse brings you back
* Order matters (they undo each other)

---

## Identity Function

### Definition

The **identity function** maps every element to itself.

```math
I_X : X \rightarrow X
```

```math
I_X(x) = x
```

---

### Properties of Identity Function

#### 1. Preservation

* The identity function **does not change** any element

#### 2. Linearity

* It is a linear transformation
* Satisfies:

  ```math
  I(ax + by) = aI(x) + bI(y)
  ```

#### 3. Neutral Element

* For any function ( f ):

  ```math
  f \circ I = I \circ f = f
  ```

#### 4. Self-Inverse

* The identity function is its **own inverse**

  ```math
  I^{-1} = I
  ```

---

## Identity Matrix

### Definition

The **identity matrix** $ I_n $:

* Is an ( n \times n ) matrix
* All diagonal elements are **1**
* All other elements are **0**

Example (3×3):

```math
I_3 =
\begin{bmatrix}
1 & 0 & 0 \\
0 & 1 & 0 \\
0 & 0 & 1
\end{bmatrix}
```

---

### Key Property

For any compatible matrix ( A ):

```math
AI = IA = A
```

This mirrors how the identity function behaves.

## When Does a Function Have an Inverse?

### Short Answer:

👉 **Only if the function is bijective**

---

## Bijective Function

A function is **bijective** if it is both:

* **Injective**
* **Surjective**

---

### Injective (One-to-One)

A function is **injective** if:

* Different inputs always give different outputs

Formally:

```math
f(x_1) = f(x_2) \Rightarrow x_1 = x_2
```

Meaning:

* No two elements in the domain map to the same element in the codomain

---

### Surjective (Onto)

A function is **surjective** if:

* Every element in the codomain **Y** is mapped to by **at least one** element in the domain **X**

Formally:

```math
\forall y \in Y, \exists x \in X \text{ such that } f(x) = y
\\
\forall - forall
\\
\exists - exists
```

Meaning:

* No element in the codomain is left unused

---

## One-Line Intuition 

> **An inverse function exists only when every output comes from exactly one input.**
