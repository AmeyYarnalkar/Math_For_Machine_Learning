## Linear Algebra (ML perspective)

**Linear algebra in ML = a way to store data and apply the same math to huge amounts of data at once.**

It is essential for representing, manipulating, and optimizing data using **vectors and matrices**.

---

## The 2 Core Ideas of Linear Algebra in ML

### 1. Vector = One data point

A vector is just a list of numbers.

Example:

```
[size, bedrooms, age] → [1200, 3, 10]

```

ML does **not see objects**, it sees **numbers**.

---

### 2. Matrix = Dataset

Stack many vectors → you get a matrix.

- Rows → data points
- Columns → features

Instead of looping row by row, ML performs **one operation on the entire matrix**, which makes it fast.


## Applications of Linear Algebra in ML

- **Data Representation & Manipulation**
    
    → Store and transform data using vectors and matrices.
    
- **Dimensionality Reduction**
    
    → Reduce unnecessary features while keeping important patterns.
    
- **Model Training**
    
    → Solve equations and perform matrix operations to learn weights.
    
- **Neural Networks**
    
    → Forward propagation = matrix multiplication
    
    → Backpropagation = adjusting weights to improve decisions
    

---

## One line you should remember

> Machine learning models don’t think — they multiply matrices and adjust weights.
> 

That’s linear algebra in ML.
