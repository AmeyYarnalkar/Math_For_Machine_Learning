## Scalar Multiplication 

### What it means

**Scalar multiplication = scaling a vector.**

You multiply **every element** of the vector by a single number.

---

### Syntax

If

```
v = (x, y)
k = scalar

```

Then

```
k · v = (k·x, k·y)

```

---

### Intuition (movement / geometry)

- `k > 1` → vector gets **longer**
- `0 < k < 1` → vector gets **shorter**
- `k = 0` → vector becomes **zero**
- `k < 0` → vector **flips direction**

Example:

```
v = (2, 3)
2 · v = (4, 6)

```

Same direction, double length.

---

### ML usage

- Scaling features
- Adjusting learning rates
- Weight updates during training

> Scalar multiplication changes size, not meaning/direction (unless negative).
> 

---

## Element-wise Vector Multiplication (Hadamard Product)

### What it means

**Element-wise multiplication = multiply matching elements only.**

This is **NOT** dot product.

---

### Syntax

If

```
A = (a1, a2, a3)
B = (b1, b2, b3)

```

Then

```
A ⊙ B = (a1·b1, a2·b2, a3·b3)

```

(Same position × same position)

---

### Intuition

Think **feature-wise interaction**:

> “How much does feature i of A interact with feature i of B?”
> 

Example:

```
A = (2, 3, 4)
B = (10, 0.5, 1)

A ⊙ B = (20, 1.5, 4)

```

Each feature scaled **independently**.

---

### ML usage (very important)

- Feature weighting
- Attention mechanisms
- Gating (LSTM, GRU)
- Masking (turn features on/off)

Example:

```
features ⊙ importance_mask

```

---

## 3️⃣ Do NOT confuse these three (critical)

| Operation | Result | Meaning |
| --- | --- | --- |
| Dot product | Scalar | Overall similarity |
| Scalar × Vector | Vector | Resize whole vector |
| Element-wise mult | Vector | Feature-wise scaling |

---

## One brutal line to remember

> Dot product compares vectors, scalar multiplication resizes vectors, element-wise multiplication modifies features.
>
