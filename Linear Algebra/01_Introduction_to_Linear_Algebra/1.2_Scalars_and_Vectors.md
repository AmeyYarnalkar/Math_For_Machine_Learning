## Scalars (Data Science / ML)

**Scalar = a single number.**

It represents **one piece of information**.

### Key Points

- **Zero-dimensional** → no direction, no structure
- **Magnitude only** → tells *how much* of something
- **Atomic** → basic building block of all data

### Examples

- Temperature: `25°C`
- Accuracy: `0.95`
- Loss value: `0.12`
- Learning rate: `0.001`

> A scalar answers only “how much?”
> 

---

### Direction in Scalars (important clarification)

- A scalar **does not have direction**
- A `+` or  sign only shows position relative to a reference point
    
    (e.g., `-5°C` means below zero, not a spatial direction)
    

So:

> Scalars live on a single line, not in space.
> 

---

## Vectors (Data Science / ML)

**Vector = an ordered list of numbers.**

It represents **both magnitude and direction in space**.

### Key Points

- **One-dimensional structure** (but lives in multi-dimensional space)
- **Ordered** → position of numbers matters
- Represents **direction + size**

### Example

```
[size, bedrooms, age] → [1200, 3, 10]

```

Here:

- Each value is a **feature**
- The vector represents **one data point**

---

### Scalars vs Vectors (one-line difference)

- **Scalar:** one number → *how much*
- **Vector:** list of numbers → *where and how strong*

---

### ML intuition (remember this)

- **Scalar** → result or control value
    
    (loss, accuracy, learning rate)
    
- **Vector** → data point or model weights
